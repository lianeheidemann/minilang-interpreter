## Simplified Programming Language Interpreter

MinyLang is a custom language interpreter implemented in Python. It performs lexical analysis, parsing, and execution for basic structures such as variables, expressions, and conditionals.

The project demonstrates core concepts in programming-language and interpreter design.

---

## Language Features

- Lexical analysis with a regex-based lexer
- Parsing and source-structure interpretation
- Command execution
- Dynamic variables
- Mathematical operations
- Logical operators
- Conditional structures (`if / else`)
- Main block (`main { }`)
